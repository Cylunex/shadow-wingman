# shadow-wingman · 恋爱与社交沟通陪练

一套可移植的中文 AI 角色扮演技能，用来练习搭讪、聊天、邀约、约会、相亲和关系沟通，也可以复盘练习或现实对话。

它的目标不是让 AI 执行一套恋爱状态机，而是提供一间有素材、有反馈、有边界的即兴排练室：人物像真人一样拥有自己的节奏和选择；用户从真实反应中练习观察、表达、推进和体面收尾。

## 设计原则

- **角色扮演优先**：默认只演互动对象，不同时跳出教练、导演和复盘师抢戏。
- **情境判断优先**：不使用精确“兴趣值”遥控反应，不把单个信号解释成确定答案。
- **自然语言优先**：用户可以直接说“换个难一点的”“先停一下帮我看看”，不必记住命令。
- **按需加载**：人物、场景、知识、例句、信号和评分分别存放，需要时才读取。
- **复盘与表演分离**：演的时候自然演；用户要求复盘时再分析或评分。
- **尊重自主权**：明确拒绝、停止、拉黑或持续不回应时不继续推进。

## 使用方式

### 作为 skill

把仓库接入支持 `SKILL.md` 的 AI agent。技能会在用户要求恋爱/社交角色扮演、陪练或对话复盘时触发。

### 直接使用提示

也可以把 [`SKILL.md`](SKILL.md) 提供给任意 AI，再按需补充 `references/` 中的单个文件。

用户可以自然地说：

- “模拟一个朋友聚会刚认识的女生，我来开场。”
- “换个更慢热的人，回复短一点。”
- “暂停，告诉我刚才哪里显得用力。”
- “复盘这段真实聊天，不用打分。”
- “给我三个更自然的邀请方向。”

原有 `/开始`、`/教练`、`/提示`、`/弹药`、`/状态`、`/复盘`、`/换人`、`/难度`、`/旁白`、`/继续` 仍可作为快捷方式，但不是协议，也没有固定输出格式。

## 目录

```text
shadow-wingman/
├── SKILL.md                 # 轻量入口：即兴原则、模式切换、资料路由、边界
├── references/
│   ├── roles.md             # 人物种子
│   ├── scenarios.md         # 情境种子
│   ├── knowledge-base.md    # 沟通知识与案例
│   ├── ammo.md              # 卡壳时的表达灵感
│   ├── signals.md           # 互动反馈与边界判断
│   └── scoring.md           # 可选复盘量表
├── progress/_template.md    # 可选、私密的练习记录模板
└── corpus/                  # 原始课程、整理稿与内容路由，供维护蒸馏使用
```

`corpus/` 是维护素材，不是运行依赖。实际使用时应优先加载少量、与当前任务直接相关的 `references/`。

## 练习建议

短时间反复练一个真实难点，比一次套完整流程更有效。同一情境可以换人物、媒介或关系阶段重练；复盘时优先找一个下次能验证的变化，而不是追求固定“正确台词”。

如果要长期记录，把 `progress/_template.md` 复制为私人日志。首次保存前应先征得用户同意，用户也可以只记摘要而不保存完整对话。
