# Shadow Wingman

Shadow Wingman 是恋爱与社交沟通陪练。它帮助用户梳理事实、理解情绪、准备表达和复盘互动，
不替用户操控他人，也不把关系简化成套路或评分游戏。

## 理念

- 先区分事实、感受、推测和目标；
- 尊重对方边界，不鼓励欺骗、施压或情绪操控；
- 建议应符合用户真实语气，而不是生成模板化“高情商话术”；
- 重要决定由用户完成，Agent 只提供视角和练习。

## 主要功能

- 对话与关系情境梳理；
- 消息草稿、语气调整和多版本表达；
- 冲突、邀约、拒绝、道歉和边界沟通演练；
- 角色扮演与可能回应模拟；
- 互动复盘和长期模式观察。

## 使用方式

项目可以作为独立 Prompt/Skill 使用，也可以由 Shadow Agent 按场景装载。个人真实聊天、身份和
关系资料不得提交到仓库；如需长期记录，应进入受权限保护的领域存储。

## 目录

- `prompts/`：沟通与复盘提示；
- `skills/`：可装载能力；
- `examples/`：脱敏示例；
- `docs/`：扩展说明（存在时）。
